Problemas reais,
soluções no ar.

Situações em que identifiquei um atrito no dia a dia, desenhei a solução e a coloquei para funcionar. O destaque é uma ferramenta que criei para quem desenvolve no Fluig.

Case em destaqueExtensão VS CodeGitAutomação

Fluig Tracker

Versão comunitária da extensão Fluig para VS Code, com integração Git: cada exportação bem-sucedida vira, sozinha, um commit enviado ao GitHub.

Conheça esse case
0registros manuais por exportação: o commit e o push saem sozinhos
// fluxo de exportação → github

Exportar artefatos para o Fluig faz parte da rotina de quem desenvolve na plataforma, mas o registro de cada exportação dependia de uma operação manual, repetida toda vez.

Parti da extensão da comunidade Fluiggers e adicionei uma camada de integração com Git: ao concluir uma exportação com sucesso, a extensão cria o commit e faz o push para o repositório remoto configurado.

O histórico das exportações passa a ser acompanhado direto pelo GitHub, sem registrar cada operação à mão. A extensão é distribuída em pacote .vsix, instalável pelo próprio VS Code.

Limitação atual: o pacote usa um caminho local específico para o repositório de atividade e precisa ser adaptado em outros ambientes.
