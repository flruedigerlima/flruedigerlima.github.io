Problema

Histórico manual

Exportar para o Fluig faz parte da rotina de quem desenvolve na plataforma, mas registrar cada exportação dependia de uma operação manual, repetida toda vez.

Solução

Commit e push sozinhos

Parti da extensão da comunidade Fluiggers e adicionei a integração com Git: ao concluir uma exportação com sucesso, a extensão cria o commit e faz o push para o repositório remoto configurado.

Resultado

Histórico no GitHub

O histórico das exportações passa a ser acompanhado direto pelo GitHub, sem registrar cada operação à mão. Distribuição em pacote .vsix, instalável pelo próprio VS Code.

Limitação atual: o pacote usa um caminho local específico para o repositório de atividade e precisa ser adaptado em outros ambientes.
